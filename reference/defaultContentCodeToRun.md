# Load default content for `CodeToRun.R`

Load default content for `CodeToRun.R`

## Usage

``` r
defaultContentCodeToRun(studyNumber)
```

## Arguments

- studyNumber:

  Character string identifying the study number, e.g. `"P1-C1-001"`.

## Value

A character vector containing the default contents of
`extras/CodeToRun.R`.
