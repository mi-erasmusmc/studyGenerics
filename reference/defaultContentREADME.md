# Load default content for `README.Rmd`

Load default content for `README.Rmd`

## Usage

``` r
defaultContentREADME(studyNumber)
```

## Arguments

- studyNumber:

  Character string identifying the study number, e.g. `"P1-C1-001"`.

## Value

A character vector containing the default contents of `README.Rmd`, to
be rendered into `README.md` through .
