# Insert default documentation files

Creates default `NEWS.md`, `README.Rmd` and `LICENSE.md` (Apache License
2.0) files.

## Usage

``` r
insertDocs(studyNumber, path)
```

## Arguments

- studyNumber:

  Character string identifying the study number, e.g. `"P1-C1-001"`.

- path:

  A valid path to the study project in character.

## Value

No return value.
